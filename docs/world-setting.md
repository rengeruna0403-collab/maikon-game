## ゲーム開始時の状況

プレイヤーは「舞昆茶屋」を**祖父から引き継いだ**経営者。
ゼロから起業したのではなく、すでに存在するお店・物件・商品ラインナップを受け継いだ状態でゲームが始まる。

### 引き継いだもの

| 項目 | 状態 |
|------|------|
| 舞昆茶屋（イートイン・商品販売） | 閉店中。再開が最初のミッション |
| 舞昆の商品ラインナップ | 祖父が仕入れていた商品が棚に並んでいる（取扱中） |
| 物販チャネル（祖父の販路） | 既存の得意先・取引先が継続中。売上は入ってくる |
| アパート（物件） | 空室あり。入居者募集が最初のミッション |
| 地域との関係 | 祖父の代からのご縁があるが、プレイヤー自身はまだ顔が知られていない |

### 引き継いでいないもの（プレイヤーが新たに作るもの）

- お客様との個人的なご縁（常連・関係）
- 店のメニュー構成（祖父の時代と変えてよい）
- 経営の方向性・戦略

---

## 設定の軸：「知っているようで、知らない」

プレイヤーは子どもの頃から舞昆が身近にあった。
しかし「舞昆とは何か」「なぜお客様に喜ばれるのか」を自分の言葉で語れない。
第1章「舞昆って何？」はこの"知っているつもり"から本当の理解へ向かう物語。

## 表記ルール

- 「開店する」ではなく「**再開する**」（初回のお店オープン時）
- 「ゼロから始める」「新規開業」表現は使わない
- 商品が棚にある状態は「取扱中」（茶屋営業とは独立）
- 閉店中でも商品コーナーは機能している（祖父の販路が継続）

---

## 変更禁止事項（ゲームバランス）

以下はワールド設定変更の対象外：
- 初期資金・初期顧客数・初期商品数
- 収益計算・AI行動ロジック・BusinessReport
- QAツール（maikon-qa.js）の検証ロジック

## ブランド監修リスト（Review Required）

ゲーム内でブランド「舞昆」に関する情報を使用する前に、必ずこのリストで状態を確認すること。
状態が「承認済み」のもの以外はゲーム本文・イベント・ストーリーへ記載しない。

**状態の定義：**
- `承認済み` — 公開情報として確認済み。使用可能
- `要監修` — 事実の可能性があるが未確認。**使用禁止**
- `創作` — ゲームオリジナル。実在人物・事実との混同禁止
- `使用禁止` — 誤解・法的リスクがあるため永久禁止
