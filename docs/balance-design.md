| 行動 | キー | 採用状況 | デフォルト |

## 2. 各行動の役割定義

### buyMenu — メニュー追加

```
役割     : 即効性のある売上強化
効果期間 : 短期〜中期（購入後すぐ効果が出る）
消費     : AP + 資金（1回あたりのコストが明確）
上限     : MENU_OPTIONS 全購入済みで終了

序盤 ★★★★★  資金が少ない状態でも少額から始められる
中盤 ★★★★☆  メニュー追加の余地があれば有効
終盤 ★★☆☆☆  全購入済みになると効果消滅

短期利益 ★★★★★
長期利益 ★★☆☆☆  メニューが揃ったあとの成長手段がない

選ぶタイミング: 売上が足りないとき、APと資金に余裕があるとき
選ばないタイミング: 全メニュー購入済み、AP不足、資金繰りが厳しいとき

AI不採用理由: (現在は採用済み) 唯一の採用行動
```

---

### investRegion — 地域活動

```
役割     : 地域評価の向上による間接的な集客強化
効果期間 : 長期（地域評価は積み上げ型）
消費     : AP + 資金（効果が見えにくい）

序盤 ★★☆☆☆  資金余裕がないと選べない
中盤 ★★★☆☆  地域評価が集客に効いてくる段階
終盤 ★★★★☆  地域評価の差が入居率・来客数に出る

短期利益 ★☆☆☆☆
長期利益 ★★★★☆  地域評価50以上で入居率に恩恵（設計上）

選ぶタイミング: 資金に余裕がある、店舗数が増えてきた、地域評価が低い
選ばないタイミング: 序盤の資金不足期、AP不足時

AI不採用理由: 10seed×10試行で利益改善を確認できなかった
→ 地域評価の利益反映が現状薄い可能性が高い
```

---

### trainStaff — スタッフ研修

```
役割     : スタッフスキル向上による品質・サービス改善
効果期間 : 中期〜長期（スキルは永続的に保持）
消費     : AP + 資金（人数分の投資が必要）

序盤 ★★☆☆☆  スタッフが少ないと効果が薄い
中盤 ★★★★☆  スタッフが3〜5名になると効果が出やすい
終盤 ★★★★★  スタッフ人数が多いほど研修コスパが上がる

短期利益 ★☆☆☆☆
長期利益 ★★★★☆  スキルが積み上がると定常的な底上げが期待できる

選ぶタイミング: スタッフ3名以上、AP余裕あり、長期視点で投資したいとき
選ばないタイミング: スタッフ1名、序盤の資金不足

AI不採用理由: 10seed×10試行で利益改善を確認できなかった
→ スキルの売上反映係数が現状不十分な可能性
```

---

### buyAd — 広告出稿

```
役割     : 短期間の集客ブースト
効果期間 : 短期（広告期間のみ）
消費     : AP + 資金（継続すると高コスト）

序盤 ★★☆☆☆  開店直後の認知獲得に使えるが資金消費が重い
中盤 ★★★☆☆  新メニュー発売や閑散期に合わせると効果的
終盤 ★★★☆☆  競合との差別化に使える

短期利益 ★★★☆☆
長期利益 ★★☆☆☆  広告をやめると効果消滅

選ぶタイミング: 新メニュー追加直後、来客数が落ちている、資金に余裕がある
選ばないタイミング: AP不足、広告コストを回収できる売上見込みがない

AI不採用理由: 広告間隔 14/21/30/45/60日 の全パターンで
              平均利益差分 > 0 かつ 勝率 ≥ 60% を満たさなかった
→ 広告コストを売上増で回収するまでに時間がかかりすぎる可能性
```

---

### buyRenov — 店舗改装

```
役割     : 店舗価値向上による客単価・満足度の底上げ
効果期間 : 永続（改装効果は店舗に恒久的に残る）
消費     : AP + 資金（最も高コスト）

序盤 ★☆☆☆☆  初期投資として重すぎる
中盤 ★★★☆☆  店舗が安定してきたら価値投資として有効
終盤 ★★★★☆  複数店舗を持ってから改装でレベルアップ

短期利益 ★☆☆☆☆
長期利益 ★★★★☆  改装 Lv が上がるほど客単価・満足度に影響

選ぶタイミング: 資金に大きな余裕がある、中盤以降、メニュー追加が完了している
選ばないタイミング: 序盤、資金不足、AP不足

AI不採用理由: 10seed×10試行の全評価で
              平均利益差分・中央値がマイナス、勝率0%
→ 改装コストを回収する前に365日が終わる可能性が高い
```

## 3. 行動の住み分け（役割が重ならないよう整理）

| 行動 | 主な目的 | 効果の現れ方 | 必要な前提条件 |
|---|---|---|---|
| buyMenu | **売上を増やす** | 即時・直接的 | APと資金の最小余裕 |
| investRegion | **地域評価を上げる** | 長期・間接的 | 資金余裕と複数店舗 |
| trainStaff | **スタッフを育てる** | 中期・積み上げ型 | スタッフ3名以上 |
| buyAd | **短期集客を増やす** | 即時・一時的 | タイミングと資金余裕 |
| buyRenov | **店舗価値を高める** | 永続・間接的 | 中盤以降・大きな資金余裕 |

**理想的な行動の流れ（設計上の期待）**:
```
序盤（〜3ヶ月）
  └ buyMenu を中心に売上を上げる

中盤（3〜8ヶ月）
  ├ buyMenu の残りを埋める
  ├ trainStaff でスタッフを育てる
  └ investRegion で地域評価を積む

終盤（8〜12ヶ月）
  ├ buyRenov で店舗価値を高める
  ├ buyAd で閑散期を補う
  └ investRegion で地域との絆を深める
```

## 4. 現状との差分（問題の所在）

### buyMenu
| | 内容 |
|---|---|
| 現状 | 365日通じて最強。終盤でも使える（全購入済みにならない限り） |
| 理想 | 序盤〜中盤が最強。中盤以降は他行動で補う |
| 差分 | メニュー全購入後の「次の一手」がプレイヤーに見えない |

### investRegion
| | 内容 |
|---|---|
| 現状 | 利益改善が見えず不採用。プレイヤーも選ぶ理由がない |
| 理想 | 中盤以降に「地域評価→入居率→売上」の連鎖が見える |
| 差分 | 地域評価の利益反映が数値として薄すぎる |

### trainStaff
| | 内容 |
|---|---|
| 現状 | 利益改善が見えず不採用。育てる意味が見えない |
| 理想 | スタッフ3名以上で「研修→スキルアップ→売上安定」が見える |
| 差分 | スキルの売上反映係数が効果として実感しにくい水準 |

### buyAd
| | 内容 |
|---|---|
| 現状 | 全広告間隔でコスト回収できず不採用 |
| 理想 | 新メニュー発売直後7日間など、タイミング限定で効果2倍 |
| 差分 | 広告の「タイミング連動」効果が現状ない |

### buyRenov
| | 内容 |
|---|---|
| 現状 | 初期コストが重すぎてROIがマイナス |
| 理想 | 改装Lv3で客単価+10%など、高投資に見合うリターン |
| 差分 | 改装レベルによるスケーリング効果が薄い |

## 5. 将来の改善候補（今回は実装しない）

以下はアイデアのリスト。優先度・実装順は別途検討。

### buyMenu の終盤への誘導
```
全メニュー購入済みになったとき、
「メニューは全部揃いました。次は改装やスタッフ育成を試してみては？」
をホームに表示する
```

### investRegion の利益反映強化
```
地域評価 50 以上: 入居率 +5%
地域評価 70 以上: 来客数 +8%（地域からの口コミ）
地域評価 90 以上: 毎月イベント誘致の抽選対象になる
```

### trainStaff の効果可視化
```
研修成功: 翌月から売上 +3%（スタッフ1名あたり）
スキルLv3: 案件受諾率 +10%
スキルLv5: 月次チャレンジ難易度が1段階下がる
```

### buyAd のタイミング連動
```
新メニュー追加後7日間: 広告効果2倍
閑散月（売上が平均-20%以下）: 広告コスト30%割引
地域評価70以上: 広告クールタイム短縮
```

### buyRenov のレベルスケーリング
```
改装Lv1: 客単価 +3%
改装Lv2: 満足度 +5%
改装Lv3: 客単価 +10%、月次チャレンジ報酬 +15%
改装Lv4: 入居率 +8%（内装が良い物件として評価）
```

### 行動間の連携ボーナス（シナジー）
```
trainStaff + buyMenu 同月実施:
  スタッフがメニューを熟知し、接客品質+5%

investRegion + buyAd 同月実施:
  地域への広告として効果1.5倍

buyRenov + trainStaff 両完了:
  「良い店・良いスタッフ」として地域評価+10
```

### プレイヤーへのヒント連携
```
メニューが全購入済みになったとき → 改装・研修を提案
地域評価が20日間変化なし → 地域活動を提案
スタッフが3名以上になったとき → 初回研修を提案
資金が一定以上かつ改装未実施 → 改装を提案
```

## 付記：AI採用基準（現行）

各行動のAI採用は次の基準で判定している:

```
10seed × 10試行のフル評価で
  平均利益差分 > 0
  中央値 > 0
  勝率 ≥ 60%
の3条件を満たすこと
```

将来のバランス調整後は、この基準で再評価する。
